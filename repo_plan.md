# Repo plan

## purpose

- have a repo for skills and agents that can be used to interact with Carbon+Alt+Delete via its MCP connector
- have dedicated skills for certain features of Carbon+Alt+Delete using MCP tool calls
- have agents to describe workflows and processes that can be executed via Carbon+Alt+Delete based on the skills
-

## tooling

- use modern tooling like mise, prek, rust
- use modern linting and quality tools for md files
- use modern quality tools for skills and agent files
